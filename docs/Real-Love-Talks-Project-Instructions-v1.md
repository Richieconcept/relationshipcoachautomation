SCRIPT STYLE AND STANDARDS
The owner confirmed scripts normally run 30-50 seconds depending on the content, at least about 30 seconds. Use anonymized/fictional examples honestly. Unsafe situations need safety-sensitive advice, not automatic confrontation. No research URLs, citations, stage directions or labels such as Hook/Scene in the script itself.
